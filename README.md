# AI 기업 투자검토 3차 고도화 — 뉴스 건별 긍정·부정·위험요인 분석

## 3차 고도화 핵심: 뉴스 건별 AI 영향분석

기존 **1·2차 주가 차트**를 유지하면서 다음 기능이 추가되었습니다.

1. **관련성 및 중복 정리** — 기업명을 직접 언급한 기사를 우선 선택하고, 삼성전자 관련 약칭 뉴스는 `추정`으로 표시합니다. 다른 회사 중심이거나 중복된 기사는 `뉴스제외기록`에 남깁니다. 이 필터는 완벽한 기업 식별이 아니므로 원문을 확인하세요.
2. **기사별 OpenAI 분류** — 각 기사에 `긍정 / 부정 / 중립 / 혼합 / 판단보류`, `AI관련성`, `영향분야`, `위험요인`, `판단근거`를 붙입니다. **감성은 해당 기업에 대한 잠재 영향 방향**이며 기사 표현의 감정이나 실제 수익률 예측이 아닙니다.
3. **분석 집계** — 분류별 건수 및 비중, 부정·혼합 기사 위험요인 표, 감성 필터를 제공합니다. AI가 관련 없다고 판단한 기사는 집계에서 제외합니다.
4. **기계적 검증** — 기사 ID·원문 링크가 분석 전후 같고, 감성 레이블이 허용된 값인지 검사합니다. **기사 내용의 진위·AI 정성 판단의 옳고 그름은 검증하지 못합니다.**
5. **보고서 저장** — AI 투자검토 보고서 Markdown, 분석 Excel(`뉴스감성분석`, `뉴스감성집계`, `뉴스감성검증`, `뉴스제외기록`)에 분석 결과를 추가합니다.
6. **API 사용 안전** — 각 OpenAI 호출은 기사 최대 25개, 한 요청당 최대 5개로 나누어 사용합니다. 호출 때 토큰 이용 요금이 발생할 수 있습니다. 원치 않으면 1단계만 실행하세요.

### 화면에서 실행 순서

- **1단계 · 데이터 수집 및 pandas 분석**: 재무/주가/뉴스 수집과 뉴스 관련성 필터만 수행하고 OpenAI는 호출하지 않습니다.
- **뉴스 · 기사** 탭에서 **기사별 AI 긍정·부정·중립 분석 실행**: 기사마다 감성·판단근거/위험요인을 확인합니다.
- **2단계 · AI 투자검토 보고서 생성**: 감성 분석 결과를 참조해 수익성·안정성·주가 추세·뉴스 위험요인 보고서를 작성합니다. 뉴스 탭의 감성 분석을 먼저 실행하지 않았으면 자동으로 분석한 뒤 보고서를 작성합니다.
- Excel 및 Markdown 보고서 파일을 다운로드합니다.

**중요 한계:** 원문 기사를 수집·검증하지 않고 뉴스 제목과 검색 요약만 분석합니다. 언론 보도가 사실인지, 실제로 주가에 어떤 영향을 미쳤는지 판정하지 않습니다. 같은 사실이 여러 기사로 보도되면 중복 제거 후에도 남을 수 있으며, 감성 기사 수를 투자 점수로 해석하면 안 됩니다.

### 선택: 공개 앱의 AI 버튼 보호

공개 URL에서 누구나 OpenAI API 호출을 반복하면 비용이 발생할 수 있습니다. Streamlit App Settings → Secrets에 다음 값을 추가하는 것을 권장합니다.

```toml
AI_ACCESS_CODE = "본인이_정한_길고_예측_어려운_비밀번호"
```

로컬 `.env`에는 `AI_ACCESS_CODE=본인이_정한_비밀번호`를 넣습니다. 설정하면 왼쪽 사이드바에서 이 코드를 입력해야 AI 분석/보고서 버튼이 활성화됩니다. **설정하지 않으면 기존처럼 AI 버튼이 공개 상태**이므로 배포 전 설정을 권장합니다. 이 방식은 간단한 비용 방지용 공유 비밀번호이며, 완전한 사용자 인증·호출량 제한을 대신하지 않습니다.

### UI에서 사용하는 데이터와 계산 방식

- 기간 필터는 **현재 시각이 아닌 실제 가장 최근 조회된 거래일**을 기준으로 합니다. 낡은 데이터라도 미래 날짜를 생성하지 않습니다.
- 이동평균선(SMA)은 해당 거래일까지 **최근 N거래일 종가의 단순 평균**이며, N거래일 미만이면 표시하지 않습니다.
- 선택 기간 수익률은 **선택 기간 첫 거래일 종가 대비 마지막 거래일 종가** 변화율입니다. 사용자가 지정한 '1개월'과 동일한 달력 날짜의 정밀 총수익률을 뜻하지 않습니다.
- 기간 최고·최저가는 정상적인 **OHLC 자료의 장중 고가·저가**입니다. 종가 최고·최저가와 다릅니다.
- 빨강은 해당 거래일의 양봉(종가 ≥ 시가), 파랑은 음봉을 의미합니다. 이동평균선이나 거래량 급증은 투자 신호가 아닙니다.
- 금융위원회 주식시세 V2는 **일별·비실시간**입니다. 사용자 증권사의 정규장 가격, 장중 가격 또는 시간외 가격과 다를 수 있습니다.
- 공공데이터 조회 실패 시 `pykrx`, `yfinance`로 대체될 수 있습니다. **데이터 출처는 UI와 결과에 표시되며**, Yahoo Finance의 수정주가는 공식 비조정 시세와 달라질 수 있습니다.

## 핵심 기능

기업명 `삼성전자` 입력 → 금융위원회 기업기본정보 API로 법인등록번호 확인 → 금융위원회 기업 재무정보 API로 사업연도별 매출·영업이익·순이익·부채·자본 조회 → **금융위원회 주식시세정보 V2 API**로 시가·고가·저가·종가·거래량·거래대금 조회 → 뉴스(NewsAPI, SerpAPI, Google 뉴스 RSS) 수집 → **기업 관련 뉴스 선별 및 건별 OpenAI 감성 분석** → **pandas 분석**(결측·중복·수익성·안정성·기초 통계) → Streamlit 차트/엑셀 다운로드 → **OpenAI 투자검토 보고서**(수익성·안정성·주가 추세·뉴스 위험 요인·수치 사실검증).

- 종목코드 검색: 삼성전자·SK하이닉스는 사전 확인된 코드로 조회하고 다른 기업은 pykrx에서 탐색합니다. 정확히 일치하는 기업명이 여러 개의 법인번호로 조회되면 임의 선택하지 않고 확인을 요청합니다.
- 재무 연도: 최근 완료된 사업연도 최대 3개. **연결 우선, 별도 차선**으로 선택하며 누락 여부와 기준을 표기합니다. 데이터가 조회되지 않으면 임의로 숫자를 생성하지 않습니다.
- 주식시세: **금융위원회 공공데이터 API가 우선**입니다. 연결이 실패하면 pykrx → yfinance 순으로 시도하고, 대체출처를 표·Excel에 표시합니다.
- 뉴스: **NewsAPI → SerpAPI → Google 뉴스 RSS** 순으로 시도합니다. 기사 전문이 아닌 제목·검색 요약만 사용하며, 기업 관련성/중복을 사전 검사한 뒤 기사별 AI 감성을 분류합니다.
- AI 보고서: OpenAI가 수익성·안정성·주가 추세·뉴스 위험 요인·종합 의견의 **정성 부분만 생성**합니다. 표와 수치 검증은 pandas 계산 결과를 그대로 사용합니다. AI 문장의 진실성 및 기사 원문 진위는 완전히 자동검증되지 않습니다.

## 2. .env 인증키

```dotenv
DATA_GO_KR_API_KEY=본인의_공공데이터포털_일반인증키
FINANCE_API_KEY=
STOCK_API_KEY=
OPENAI_API_KEY=본인의_새_OpenAI_API_키
OPENAI_MODEL=gpt-4.1-mini
NEWS_API_KEY=본인의_NewsAPI_키
SERPAPI_KEY=본인의_SerpAPI_키
AI_ACCESS_CODE=선택_공개_앱_AI_호출_보호_비밀번호
```

- **공공데이터 인증키가 하나라면** `DATA_GO_KR_API_KEY`에만 입력하고 `FINANCE_API_KEY`, `STOCK_API_KEY`는 비워 두세요. 별개 키로 관리한다면 두 변수에 따로 지정할 수 있습니다.
- **기업기본정보 API / 기업 재무정보 API / 주식시세정보 API** 각각의 공공데이터포털 활용신청이 필요합니다. 주식시세 API 승인만으로 재무/기본 API의 승인이 보장되지는 않습니다.
- 뉴스: `NEWS_API_KEY`가 설정되어 있으면 먼저 시도하고, 실패하면 `SERPAPI_KEY`, 마지막으로 Google 뉴스 RSS를 시도합니다. 두 뉴스 API 키는 비워 두어도 됩니다. 무료 플랜에서는 뉴스 수집 범위/호출 횟수 제한이 있을 수 있습니다.
- `OPENAI_API_KEY`가 없으면 **1단계 데이터 분석만** 수행할 수 있습니다. 실시간 OpenAI 호출은 사용자 계정에 요금이 발생할 수 있습니다.
- 환경변수 이름을 정확히 맞추세요. 키 앞뒤 공백, 따옴표, 줄바꿈이 없도록 합니다. 인증키를 화면에 출력하지 않습니다.
- **이전에 스크린샷으로 노출된 OpenAI/NewsAPI/SerpAPI 키는 해당 발급처에서 폐기·재발급하여 새 키로 교체하세요.** `.env`는 GitHub에 올리지 마세요.
